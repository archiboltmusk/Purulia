How this estimate works

After a warm-up, we take five HTTP round trips and three transfers in each direction, increasing payload size when needed. Values are medians. Short, incomplete, failed or interrupted transfers invalidate the test. This single-connection estimate includes HTTP overhead; it is not a certified test of ISP capacity. VPNs, devices and congestion affect it.

Browser measurements and location can be manipulated. Email sign-in reduces abuse; it does not verify these values.
